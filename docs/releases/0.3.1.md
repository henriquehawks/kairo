# Kairo 0.3.1: duas correções que atrapalhavam o uso

Esta versão corrige dois problemas chatos: o erro de serviço local que aparecia logo depois de instalar ou atualizar, e o cursor que pulava de campo enquanto você preenchia um formulário.

## Correções

- **O erro "não foi possível iniciar o serviço local" na primeira abertura.** Depois de instalar ou atualizar, o Windows confere os arquivos novos antes de liberá-los, e o Kairo desistia de esperar antes de a hora chegar. Agora ele espera de verdade e, se demorar, mostra "Iniciando o serviço local…" explicando que é só desta vez, em vez de abrir com erro. Quem já usava o app normalmente nunca via esse problema; quem instalava pela primeira vez, via quase sempre.
- **O cursor voltava para o campo anterior enquanto você digitava.** Em qualquer formulário que abre numa janelinha, cada tecla digitada devolvia o cursor ao primeiro campo. Era mais visível em Finanças › Recorrentes: ao digitar o valor da conta, o número ia parar na descrição. Corrigido em todos os formulários do app.

## Antes de instalar

- No Windows, use o instalador .exe. O .msi fica só para quem já instalou por ele. Quem já tem o Kairo recebe a atualização pelo próprio app.
- No Linux, use o .deb no Ubuntu, o .rpm no Fedora ou o AppImage em outras distribuições. A atualização no Linux é manual: instale o pacote novo por cima.
- Um aviso de aplicativo não reconhecido pelo SmartScreen não é o mesmo que uma detecção de ameaça pelo Defender. Mantenha o antivírus ativo e baixe somente das releases oficiais.
