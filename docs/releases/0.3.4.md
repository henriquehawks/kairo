# Kairo 0.3.4: a conta passa a ser por convite

A conta que chegou na versão anterior agora é **só para convidados**. Se você tentar criar uma e receber um erro dizendo que o e-mail não foi convidado, é isso: o Kairo é um app feito para um grupo pequeno de pessoas, e quem cria as contas é o Henrique. Fale com ele.

Quem já tem conta continua com ela normalmente, sincronizando como antes.

E vale repetir o mais importante: **a conta é opcional.** O Kairo funciona inteiro sem ela, guardando tudo no seu próprio computador, que é como ele sempre funcionou e vai continuar funcionando.

## Antes de instalar

- No Windows, use o instalador .exe. O .msi fica só para quem já instalou por ele. Quem já tem o Kairo recebe a atualização pelo próprio app.
- No Linux, use o .deb no Ubuntu, o .rpm no Fedora ou o AppImage em outras distribuições. A atualização no Linux é manual: instale o pacote novo por cima.
- Um aviso de aplicativo não reconhecido pelo SmartScreen não é o mesmo que uma detecção de ameaça pelo Defender. Mantenha o antivírus ativo e baixe somente das releases oficiais.
