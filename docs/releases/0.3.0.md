# Kairo 0.3.0: a ilha vai para onde você quiser

Até agora a ilha ficava presa no alto da tela, no meio. Nesta versão ela sai do lugar: segure a ilha fechada e arraste para onde preferir — canto, lateral, meio da tela, embaixo. Ela lembra onde foi deixada, inclusive depois de fechar o app, e se ajeita sozinha quando você troca a resolução ou liga outro monitor.

## Novidades

- **A ilha agora se move.** Arraste a ilha fechada para qualquer ponto da tela. Um clique continua abrindo a ilha como sempre: ela só começa a se mover depois que você realmente arrasta.
- **Longe do topo, ela vira uma pílula flutuante**, com os quatro cantos arredondados e uma sombra para destacar da janela de trás. Arrastando de volta para perto da borda de cima, ela se encaixa no topo outra vez, com o recorte de entalhe de sempre, e a barra do topo abre o vão no lugar novo dela.
- **Na metade de baixo da tela, a ilha abre para cima**, para o conteúdo não sair pela borda.
- **Dá para ajustar pelo teclado.** Com a ilha fechada em foco, as setas movem de pouquinho em pouquinho, e com Shift ela anda mais rápido.
- Em Configurações › Ilha há uma linha nova, **Lugar na tela**, que mostra onde ela está e traz o botão "Voltar ao topo" para devolvê-la à posição original.

## Antes de instalar

- No Windows, use o instalador .exe. O .msi fica só para quem já instalou por ele. Quem já tem o Kairo recebe a atualização pelo próprio app.
- No Linux, use o .deb no Ubuntu, o .rpm no Fedora ou o AppImage em outras distribuições. A atualização no Linux é manual: instale o pacote novo por cima.
- Um aviso de aplicativo não reconhecido pelo SmartScreen não é o mesmo que uma detecção de ameaça pelo Defender. Mantenha o antivírus ativo e baixe somente das releases oficiais.
